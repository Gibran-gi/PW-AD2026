# COMANDOS ESENCIALES PARA GITHUB

### 1. git init
- **Descripción:** Inicia un nuevo repositorio Git en la carpeta actual.
- **Ejemplo:** `git init`

### 2. git fetch
- **Descripción:** Descarga cambios del remoto pero sin fusionarlos.
- **Ejemplo:** `git fetch origin`

### 3. git add
- **Descripción:** Añade archivos al área de preparación (staging).
- **Ejemplo:** `git add Perfil.md` o `git add .` para todos

### 4. git status
- **Descripción:** Muestra el estado de los archivos (modificados, en staging, sin seguimiento).
- **Ejemplo:** `git status`


### 5. git commit
- **Descripción:** Guarda los cambios del staging en el historial local.
- **Ejemplo:** `git commit -m "Agrega perfil"`

### 6. git push
- **Descripción:** Sube los commits locales al repositorio remoto.
- **Ejemplo:** `git push origin main`

### 7. git pull
- **Descripción:** Descarga y fusiona cambios del remoto a tu local.
- **Ejemplo:** `git pull origin main`

### 8. git clone
- **Descripción:** Clona un repositorio existente desde una URL remota.
- **Ejemplo:** `git clone https://github.com/yasimarmas/PW-AD2026.git`

### 9. git branch
- **Descripción:** Lista, crea o elimina ramas.
- **Ejemplo:** `git branch nueva-rama`

### 10. git checkout
- **Descripción:** Cambia de rama o restaura archivos.
- **Ejemplo:** `git checkout main`

### 11. git switch
- **Descripción:** Forma moderna de cambiar de rama.
- **Ejemplo:** `git switch main`

### 12. git merge
- **Descripción:** Fusiona una rama con la rama actual.
- **Ejemplo:** `git merge feature/perfil`

### 13. git log
- **Descripción:** Muestra el historial de commits.
- **Ejemplo:** `git log --oneline`

### 14. git diff
- **Descripción:** Muestra diferencias entre archivos y commits.
- **Ejemplo:** `git diff`

### 15. git remote
- **Descripción:** Gestiona los repositorios remotos.
- **Ejemplo:** `git remote -v`

### 16. git rm
- **Descripción:** Elimina archivos del seguimiento de Git.
- **Ejemplo:** `git rm archivo.txt`

### 17. git mv
- **Descripción:** Mueve o renombra archivos en Git.
- **Ejemplo:** `git mv viejo.md nuevo.md`

### 18. git stash
- **Descripción:** Guarda temporalmente cambios sin hacer commit.
- **Ejemplo:** `git stash`

### 19. git reset
- **Descripción:** Deshace cambios, mueve HEAD a un estado anterior.
- **Ejemplo:** `git reset --soft HEAD~1`

### 20. git fork (en GitHub)
- **Descripción:** No es comando de consola, es acción en GitHub que crea una copia del repo en tu cuenta para trabajar sin afectar el original.
- **Ejemplo:** Dar clic en Fork en https://github.com/yasimarmas/PW-AD2026
